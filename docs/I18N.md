# Internacionalización (i18n)

El sitio usa next-intl. El idioma se guarda en la cookie `NEXT_LOCALE`
(no cambia la URL). Idiomas disponibles: `es` (por defecto) y `en`.

## Dónde están las traducciones

- `apps/web/messages/es.json`
- `apps/web/messages/en.json`

## Cómo traducir un componente

Componente de cliente (`'use client'`):

```tsx
import { useTranslations } from "next-intl";

const t = useTranslations("Hero");
return <h1>{t("title")}</h1>;
```

Componente de servidor:

```tsx
import { getTranslations } from "next-intl/server";

const t = await getTranslations("Hero");
```

## Cómo agregar una clave nueva

1. Agregala en `es.json` y en `en.json` con el mismo nombree:

```json
{ "Hero": { "title": "Jóvenes en Órbita" } }
```

2. Usala con `t('title')`.

## Cómo agregar un idioma

1. Creá `apps/web/messages/xx.json` copiando `es.json`.
2. Agregá el código a `LOCALES` en `apps/web/src/i18n/request.ts`.
3. Agregalo a `LANGUAGES` en `apps/web/src/components/ui/LanguageSwitcher.tsx`.

## Secciones en desarrollo

Los links comentados en `Navbar.tsx` (Sistema Solar, Constelaciones) se
habilitarán cuando esas secciones estén listas. Al descomentarlos, agregá
sus claves en `es.json` y `en.json` y usá `t("clave")`.
